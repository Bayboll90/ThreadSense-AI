# ThreadSense AI

Open-source Chrome extension for discovering relevant Threads conversations, drafting replies in a configurable voice, and reviewing an approval queue before publishing.

> [!WARNING]
> Social-network automation may violate platform rules and can restrict or suspend an account. ThreadSense AI makes no anti-ban guarantee. Fresh installs and autopilot are disabled by default; start with drafts and manual approval.

## Highlights

- niche, language, keyword and author filters;
- thread analysis followed by configurable text generation;
- style learning from your own profile;
- draft queue, logs, limits, schedules and circuit breakers;
- user-defined prompts for every generation stage;
- model discovery using the API key entered by the user;
- settings import/export with credentials stripped.

Native adapters are included for Anthropic and Google Gemini. OpenAI, DeepSeek, Kimi/Moonshot, xAI, Mistral, Groq, OpenRouter, Together AI and custom OpenAI-compatible gateways use the Chat Completions protocol.

See the [Russian README](README.md) for installation, architecture, testing, safety and privacy details.
