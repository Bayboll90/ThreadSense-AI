# Contributing

1. Create a focused branch and keep private profiles, dumps and credentials out of the worktree.
2. Run `npm test` before opening a pull request.
3. Describe behavior changes, migration impact and manual UI checks.
4. Preserve the default-off posture and do not market detection-evasion or an anti-ban guarantee.
5. New AI providers need request, response, authentication, model-listing and error-path tests.
