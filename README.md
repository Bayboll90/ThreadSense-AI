# ThreadSense AI

Открытое Chrome-расширение для поиска релевантных обсуждений в Threads, подготовки комментариев в заданном стиле, черновиков собственных публикаций и контроля очереди человеком.

> [!WARNING]
> Автоматизация действий в социальной сети может нарушать её правила и привести к ограничениям аккаунта. ThreadSense AI не обещает «защиту от бана». Новая установка выключена, автопубликация отключена, а безопасный старт — только в режиме черновиков с ручным подтверждением.

## Возможности

- локальный отбор постов по нише, языкам, словам и авторам;
- двухпроходная генерация: анализ ветки, затем текст;
- обучение стилю по собственному профилю;
- очередь черновиков, журнал, лимиты, расписание и аварийные остановки;
- собственные системные инструкции для отбора, анализа, комментариев, ответов и постов;
- получение доступных моделей прямо из API после проверки ключа;
- импорт и экспорт настроек без API-ключа.

## Интерфейс

Главная страница ведёт нового пользователя по четырём обязательным шагам, а popup оставляет под рукой только состояние, темп, дневной прогресс и безопасный запуск с ручной проверкой черновиков.

## AI-провайдеры

Поддерживаются нативные API Anthropic и Google Gemini, а также Chat Completions API для OpenAI, DeepSeek, Kimi/Moonshot, xAI, Mistral, Groq, OpenRouter, Together AI и пользовательского OpenAI-совместимого шлюза.

Ключ хранится в `chrome.storage.local`. Он не включается в экспорт настроек и отправляется только выбранному API. Для максимальной изоляции используйте отдельный ключ с минимальным лимитом расходов.

## Установка

1. Скачайте архив репозитория или клонируйте его.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
4. Откройте настройки ThreadSense AI.
5. Выберите AI-провайдера, введите ключ, нажмите «Проверить» и выберите модели, которые API вернул для этого ключа.
6. Заполните нишу, поисковые фразы и стиль. Пока они пусты, агент намеренно не готов к работе.
7. Начните с пресета «Осторожный» и ручной очереди.

## Разработка и тесты

Нужен Node.js 20+; внешних npm-зависимостей у расширения нет.

```powershell
npm test
npm run test:syntax
npm run test:math
npm run test:providers
```

Публичные тесты герметичны: им не нужны аккаунт Threads, браузерный профиль или настоящий API-ключ. Проверки провайдеров используют локальные ответы-заглушки и не расходуют токены.

## Архитектура

- `extension/src/common` — схема настроек, миграции, сообщения и каталог AI-провайдеров;
- `extension/src/bg` — service worker, AI-клиент, скоринг, генерация, лимиты и состояние;
- `extension/src/content` — чтение DOM Threads и пользовательские действия;
- `extension/src/ui` — popup, настройки и окно состояния;
- `test` — статические, математические и интеграционные проверки.

Расширение не использует закрытый Threads API: оно работает с видимым интерфейсом браузера. Разметка Threads меняется без предупреждения, поэтому перед реальным использованием запускайте встроенную диагностику селекторов.

## Разрешения Chrome

`storage`, `alarms`, `tabs`, `notifications` и `scripting` нужны для настроек, расписания и работы во вкладке Threads. Разрешение `debugger` используется для надёжного ввода и диагностики в управляемой вкладке; Chrome показывает стандартное предупреждение об этом доступе. Сетевые разрешения ограничены Threads, встроенными AI-провайдерами и явно перечисленными источниками материалов. Для пользовательского API-адреса расширение отдельно запрашивает доступ к его origin.
